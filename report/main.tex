\begin{abstract}
% Written from the measured figures only. Every number here also appears in
% section 5; nothing is introduced by the abstract. Short sentences on purpose:
% an abstract that needs unpicking is a worse abstract.
A pipeline has been built to transcribe a \ocrBooks{}-book cycle of 16th-century
French romance. Its recogniser has one number to its name: a
validation error rate on a 10\% split of a single volume. The two stages behind
it have none. This report measures those two.

The first re-reads low-confidence words with a language model. To stop the
model rewriting the rest of the line, each suspect word is wrapped in
\lmark~\rmark{}, and a reply is accepted only if every byte outside the markers
comes back unchanged. The rule was run over \corrOffered{} lines from a seeded
\corrPages{}-page sample, under a design registered beforehand. Weighted to the
corpus it accepted \corrAcceptRate{} of them (95\%~CI \corrAcceptLow{} to
\corrAcceptHigh{}). It refused \corrRewritesCaught{} replies for editing text
outside the markers.

Measuring the rule also found a hole in it. On \corrFindFallbackShare{} of
those lines, the code that locates a suspect word falls back to a plain search,
which can mark the same word twice. The rule then compares the reply against a
line the pipeline itself corrupted, so an acceptance there proves nothing. The
claim holds on under a third of its own evidence.

The second stage locates a \emph{Trésor} extract in the transcribed text. It
places \locLivreAccuracyWorkbook{} of passages in the right Livre and
\locChapterAccuracyWorkbook{} in the right chapter, against a gate written
before the numbers existed. Transcription itself ran over \ocrPages{} pages
with \ocrPagesFailed{} failures, at \ocrSecondsPerPage{}~s per page.

Recognition accuracy is not measured here. The scoring code, the frozen run
records and every result CSV are released, so each figure rebuilds from
committed inputs with no GPU, no model and no network.
\end{abstract}
