The correction pass marks the words it rewrote, so a line comes back as
\qtr{et ſi \lmark cognoiſſoit \rmark le cheualier}. A line is accepted only
when the text outside the markers is unchanged, which makes an unmarked
rewrite a rejection rather than a silent edit.
